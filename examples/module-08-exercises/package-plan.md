# Package plan (Exercise 2)

| Type | Fully qualified name      | Package                                                 |
| ---- |---------------------------|---------------------------------------------------------|
| Entity | Customer                  | `com.northstar.crm.entity.Customer`                     |
| Request DTO | CustomerRequest           | `com.northstar.crm.dto.CustomerRequest`                 |
| Response DTO | CustomerResponse          | `com.northstar.crm.dto.CustomerResponse`                |
| Repository | CustomerRepository        | `com.northstar.crm.repository.CustomerRepository`       |
| Service | CustomerService           | `com.northstar.crm.service.CustomerService`             |
| Controller | CustomerController        | `com.northstar.crm.controller.CustomerController`       |
| Config | AppConfig                 | `com.northstar.crm.config.AppConfig`                    |
| Exception | CustomerNotFoundException | `com.northstar.crm.exception.CustomerNotFoundException` |

## Rules

 1.) Packages must be lowercase\
 2.) Packages must match their folder structures
