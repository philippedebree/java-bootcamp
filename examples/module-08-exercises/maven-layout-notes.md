# Maven layout notes (Exercise 1)

| File | Destination          |
| ---- |----------------------|
| `Customer.java` | `src/main/java/...`  |
| `CustomerServiceTest.java` | `src/test/java/...`  |
| `application.properties` | `src/main/resources/` |
| `sample-customers.json` (tests only) | `src/test/resources/` |
| `CODING-STANDARDS.md` | `docs/`              |
| `Customer.class` | `target/classes`      |

## Why `target/` is not committed

Target is not committed because it is generated by Maven on build.

## Mistakes to avoid

 1.) Production code in test tree
 2.) Passwords should not be commited to properties
 3.) Hand-editing classes
